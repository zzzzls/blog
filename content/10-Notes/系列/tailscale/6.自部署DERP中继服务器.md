title: 6.自部署DERP中继服务器
---

Tailscale 默认没有在中国大陆部署官方的 DERP（Detour Encrypted Routing Protocol）中继服务器。因此，当你的两个设备无法完成点对点（P2P）直连打洞时，流量就会绕道东京、香港或新加坡的官方节点，导致极高的延迟和丢包。

推荐的方案是: 使用国内云服务器 IP + 自签名证书（免域名、免备案）+ 开启客户端验证（防白嫖）

## 1. 准备服务器 + 开放端口

- 一台拥有国内公网 IP 的云服务器
- 配置防火墙（安全组）
	- TCP 36666：用于 DERP 的 HTTPS 中继流量
	- UDP 3478：用于 STUN 打洞服务

## 2. 在服务器上配置防白嫖环境

为了防止你搭建的节点被别人扫描到并盗用流量，**强烈建议**在在这台服务器上也安装并登录你自己的 Tailscale 账号

- 服务器上安装 tailscale: `curl -fsSL https://tailscale.com/install.sh | sh`
- 启动并登录: `tailscale up`

## 3. 使用 Docker 部署 DERP

1. 启动 DERP 容器

	```bash
	docker run -d \
	  --name derper \
	  --restart always \
	  -p 36666:36666 \
	  -p 3478:3478/udp \
	  -v /var/run/tailscale/tailscaled.sock:/var/run/tailscale/tailscaled.sock \
	  -e DERP_ADDR=:36666 \
	  -e DERP_STUN=true \
	  -e DERP_CERT_MODE=manual \
	  -e DERP_VERIFY_CLIENTS=true \
	  fredliang/derper
	```

	- `-v .../tailscaled.sock` 和 `DERP_VERIFY_CLIENTS=true`: 让 DERP 通过本机的 Tailscale 验证连接的客户端是不是你自己的设备，杜绝外人白嫖。
	- `DERP_CERT_MODE=manual`: 该镜像会自动生成一个自签名证书


2. 获取证书指纹  
	Tailscale 支持在没有域名的情况下通过校验自签名证书的 SHA256 指纹来建立安全连接（此功能需客户端版本 >= 1.50）。在服务器上运行以下命令，计算并输出证书指纹：

	```bash
	docker exec derper openssl x509 -in /app/certs/derp.myself.com.crt -noout -fingerprint -sha256 | awk -F'=' '{print $2}' | tr -d ':' | tr 'A-Z' 'a-z'
	```

## 4. 在 tailscale 控制台配置 ACL

```json
// ... 你原有的其他配置 ...
  "derpMap": {
    // 设为 false 表示保留官方节点作为备用（推荐），设为 true 则完全禁用官方节点
    "OmitDefaultRegions": false, 
    "Regions": {
      "900": {
        "RegionID": 900,           // 自定义区域ID，必须在 900-999 之间
        "RegionCode": "cn-myderp", // 区域代码，自己随便起名
        "RegionName": "China Private DERP", // 区域名称
        "Nodes": [
          {
            "Name": "900a",
            "RegionID": 900,
            "HostName": "derp.myself.com", // 保持默认即可，与镜像生成的证书对应
            "IPv4": "1.2.3.4",             // 【修改这里】填入你云服务器的公网 IP
            "DERPPort": 36666,             // 【修改这里】填入你的 TCP 端口
            "STUNPort": 3478,              // 【修改这里】填入你的 UDP 端口
            "CertName": "sha256-raw:这里填入第三步获取的64位证书指纹" // 【修改这里】
          }
        ]
      }
    }
  }
}
```

## 5. 验证与测试

### 查看网络状态

```bash
tailscale netcheck
```

- 成功标志: 在输出的列表中，你应该能看到 China Private DERP (cn-myderp) 出现在最上方, 且延迟只有十几到几十毫秒。同时 Nearest DERP 会变成 China Private DERP

### 测试两台设备间的连接

```bash
tailscale ping <ip>
```

- 如果一开始不能直连, 它会显示 via DERP(cn-myderp). 并且延迟很低
