## 登录与登出

| 命令               | 说明                           |
| ---------------- | ---------------------------- |
| `tailscale up` | 连接到 tailscale 网络 (首次会生成登录链接) |
| `tailscale down` | 断开当前设备 tailscale 连接 (保留配置)   |
| `tailscale logout` | 登出当前账户, 清除本地密钥和配置            |
| `tailscale login` | 重新登录 (通常用于切换账户)              |

## 基础状态与信息

| 命令                    | 说明                 |
| --------------------- | ------------------ |
| `tailscale status` | 显示当前 tailnet 的设备列表 |
| `tailscale ip` | 显示本机 tailnet ip 地址 |
| `tailscale whois [ip]` | 查看指定节点详细信息         |
| `tailscale switch [账户]` | 切换登录的 tailscale 账户 |

## 网络

| 命令                            | 说明               |
| ----------------------------- | ---------------- |
| `tailscale ping [IP或主机名]` | 测试到另一台设备的延迟和连通性  |
| `tailscale netcheck` | 检查 NAT, DERP 连接情况等 |
| `tailscale debug derp [region]` | 查看 DERP 服务器状态    |

## 其他

| 命令                                 | 说明                        |
| ---------------------------------- | ------------------------- |
| `tailscale ssh [主机名或IP]` | 通过 tailscale 安全地 SSH 到另一台设备 |
| `tailscale file cp <本地文件> <目标设备>:` | 将文件发送到另一台设备               |
| `tailscale set` | 修改当前设备的偏好设置 (如接受路由、出口节点等)  |
| `tailscale get` | 获取当前设备的偏好设置               |
